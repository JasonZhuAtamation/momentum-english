资源与使用方法

基于 2026 年 10 月核对的官方网站、应用商店描述与开源项目文档。系统只提供课程安排和手动登记，不宣称能获取第三方 App 的账号数据。

把练习变成可用的英语

先留独立尝试，少量纠错，关提示再试，再换场景。点开需要的一项即可。

小练习：先说今天做了什么（I checked a field.），再向同事确认问题（Could you say that again?）。Salesforce、站会或问题澄清都用虚构例子，按水平逐步加难。

现有训练工具

避免重复劳动：TypeWords 管听写和错词自动复习；Relingo 管阅读过程中的生词高亮与收藏；本系统只登记练习是否完成和少量需要迁移到新句子的表达。小鹦看看负责一段视频反复听，而不是每天找新视频。

数据与设置

正式使用时，数据存储在你的 Supabase PostgreSQL，并通过 RLS 限制为本人可见。

学习日历

调整开始日期只改变排期，不删除既有打卡；支持周一至周六，周日休息；首周只显示开始日期以后的日子，周数仍按周一锚定。

Supabase 连接

项目已预配置，通常无需修改。使用下方邮箱和密码登录；仅在切换项目时修改公开配置。

禁止在前端填写 service_role 或 secret key。

邮箱与密码登录

使用你在 Supabase Dashboard 创建并确认的账号。密码只在本页输入，不发给助手。

输入后登录；提交时清空密码框。每个浏览器或设备首次登录一次，之后由 SDK 管理会话。

备份与恢复

推荐每周导出一次。云端导入时会逐条 upsert，同 ID 记录可能被备份内容覆盖，请先保存当前数据备份。

演示模式和云端账号的数据相互隔离。不会悄悄将本机数据覆盖云端。

当前处于本机演示模式：可以试用和打卡，数据只存储在当前浏览器。连接 Supabase 且邮箱登录成功后才启用云端同步。
